# Simple Banking System with Analytics

A Python-based banking application that manages transactions and provides visual analytics using Matplotlib.

## Features
- **Account Management:** Deposit and Withdraw with balance tracking.
- **Data Persistence:** Automatically saves transactions to a JSON file.
- **Logging:** Tracks all activities in a `bank.log` file.
- **Visual Analytics:** Generates charts for balance history and transaction trends.
- **Modern Python:** Built using `dataclasses`, `enums`, and `typing`.

## 🛠️ Technologies
- **Python 3.12**
- **Matplotlib** (for charts)
- **JSON & Logging** (built-in)
